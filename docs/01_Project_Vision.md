# Project Vision

## Goal

Create a self-hosted note-taking platform focused on:

-   Notebook → Section → Page hierarchy
-   Rich text editing
-   Password-protected notebooks and sections
-   Offline-first architecture
-   Fast search
-   AI-ready foundation
-   Cross-platform accessibility

## Long-Term Vision

Hollow should become a personal knowledge management system capable of
handling notes, journals, research, whiteboards, PDFs, drawings, and
AI-assisted workflows.
